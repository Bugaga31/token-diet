# ИНСТРУКЦИЯ ДЛЯ ЧЕЛОВЕКА — как запускать token-dietTOP

> Привет! Это твой проект — **token-diet**. Здесь всё: сжатие токенов,
> интеллект для нейронок, инвестиции, телеграм-разведка, память.
> Эта инструкция — для тебя, человека. Для нейронки есть отдельный файл:
> `instructions/ИНСТРУКЦИЯ_ДЛЯ_НЕЙРОНКИ.md`

---

## 1. Что это такое

**token-diet** — библиотека, которая:
- 💰 **Сокращает токены** (до 50-65% экономии на запросах к нейронкам)
- 🧠 **Повышает интеллект** нейронки (техники рассуждений, армия моделей)
- 📈 **Помогает с инвестициями** (T-Invest API, сигналы, портфель)
- 🔍 **Собирает разведку** (Telegram-каналы, веб, браузер)
- 💾 **Хранит память** (Obsidian) — новая нейронка подхватывает всё за минуту

---

## 2. Установка (5 минут)

```bash
cd ~/token-dietTOP
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
pip install tiktoken fastapi uvicorn httpx tinkoff-invest-python pytest
python3 -c "from token_diet import core; print('OK')"
```

## 3. Проверка что работает

```bash
python3 -m token_diet.cli --help        # список всех команд
python3 -m pytest tests -x -q           # 1300+ тестов (~9 минут)
```

---

## 4. Что умеет (главные команды)

```bash
# Сжатие текста (экономия токенов)
python3 -m token_diet.cli diet 'твой длинный текст'

# Армия нейронок — спросить все модели разом
python3 -m token_diet.cli army 'вопрос' --omni

# Память (Obsidian): remember = заголовок + текст
python3 -m token_diet.cli memo remember 'полюс' 'записать важное про полюс'
python3 -m token_diet.cli recall 'что я записывал про полюс'

# Инвестиции (нужен токен Т-Инвестиций в .env)
python3 -m token_diet.cli portfolio
python3 -m token_diet.cli status         # фон + портфель + лучший кандидат
python3 -c "from token_diet.tinkoff_invest import TinkoffInvest; print(TinkoffInvest().get_quote('SBER'))"

# Телеграм-разведка
python3 -m token_diet.memory_cli tg-search 'что пишут про полюс'

# Парсинг сайтов
python3 -m token_diet.cli scrape https://сайт.ру

# Глаза: вопрос vision-модели про экран или картинку
python3 -m token_diet.cli eyes 'что на экране?'
python3 -m token_diet.cli eyes 'опиши' --image photo.png

# Ускорение компа
python3 -m token_diet.cli turbo

# API-сервер (OpenAI-совместимый прокси с экономией)
python3 -m token_diet.cli server
```

## 6. Память (Obsidian)

- Папка памяти: `~/token-diet-memory/`
- Новая нейронка читает её командой:
  `python3 -m token_diet.memory_cli recall 'кто мой хозяин'`
- Хочешь экспортировать всё в один файл (удобно кинуть нейронке):
  `python3 -m token_diet.memory_cli export`
