## 🏆 Конкурентная стратегия

### Почему token-diet выигрывает

| Фактор | Конкуренты | token-diet |
|---|---|---|
| **Цена** | $49-$500/мес (Portkey, Not Diamond) | **Бесплатно (MIT)** |
| **Открытость** | Закрытый код (The Token Co, Not Diamond) | **Полный open-source** |
| **Экология** | Никто не считает CO₂ | **Green Calculator — уникально** |
| **Качество** | Нет проверки фактов | **Equivalence Gate — уникально** |
| **Простота** | Сложная настройка (Portkey) | **Одна команда: `token-diet serve`** |
| **Совместимость** | Привязка к платформе | **OpenAI-совместимый прокси для всего** |

### Стратегия «снизу вверх»

1. **Фаза 1 (сейчас)**: Завоевать разработчиков — open-source, MIT, pip install
2. **Фаза 2 (3 мес)**: Завоевать команды — self-hosted сервер, дашборд, плагины
3. **Фаза 3 (6 мес)**: Завоевать компании — enterprise, SaaS, поддержка
4. **Фаза 4 (12 мес)**: Стать стандартом — каждая LLM-библиотека использует token-diet

### Ключевые ставки

1. **Open-source побеждает SaaS** — разработчики выберут бесплатное/открытое
2. **Экология станет must-have** — регуляторы потребуют отчётность по CO₂
3. **Локальное > облачное** — компании хотят контроль над данными
4. **Простота > функциональность** — одна команда вместо 10 конфигов

## 🔬 Технологический радар

### Сейчас строим
- [x] Neural Scorer (без GPU)
- [x] Agent Supervisor (петли + tool calls)
- [ ] Rust бэкенд

### Следим
- Speculative decoding (50-60% экономии — пока только self-hosted)
- Mamba/SSM-based компрессоры (быстрее Transformer)
- CoT distillation (сжатие рассуждений)
- Provider-native caching (Anthropic/OpenAI cache API)

### Отложили (не сейчас)
- Собственная LLM для компрессии (дорого, медленно, сложно)
- Browser extension (маленький рынок)
- Mobile SDK (пока нет спроса)
